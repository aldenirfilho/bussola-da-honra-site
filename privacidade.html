O que acontece com suas respostas?

As reflexões são processadas no dispositivo e ficam apenas na memória da página aberta. O aplicativo não envia suas respostas a um servidor, não cria uma conta e não inclui ferramentas de publicidade ou análise de comportamento.

Salvar e compartilhar

Você escolhe quando exportar. No navegador, o registro é baixado como arquivo. Na versão nativa, um arquivo temporário é criado para abrir o menu do sistema e removido quando esse menu termina. Se houver interrupção, o aplicativo tenta removê-lo na próxima abertura. A cópia que você salvar ou enviar permanece no destino escolhido, sob as regras desse destino.

Trocar de página ou fechar o aplicativo pode apagar respostas não exportadas. Não use o projeto para registrar informações identificáveis de pacientes ou de terceiros.

Disponibilidade sem internet

O aplicativo web pode guardar páginas e materiais públicos no cache do navegador após uma primeira conexão. Você pode remover esse cache nas configurações. Na versão nativa, os arquivos públicos estão incluídos no pacote instalado.

Links e hospedagem

Ao abrir links externos, passam a valer as práticas dos respectivos serviços. Os provedores que hospedam o site podem registrar informações técnicas de acesso. O projeto não usa esses registros para avaliar suas decisões. Nenhuma cobrança está ativa nesta edição.

Precisa de ajuda?

Se algo falhar, informe a tela, o dispositivo e os passos para reproduzir. Registrar um problema no GitHub ↗ exige uma conta GitHub. Esse canal é público: não publique respostas pessoais, dados médicos, documentos ou informações de pagamento.

Para exportar, conclua seu exercício e use o botão de download. No celular nativo, escolha um destino no menu de compartilhamento. Confira o arquivo antes de sair.

Limites do projeto

HONRA é um roteiro educativo autoral. Não é uma escala validada, não decide por você e não substitui atendimento clínico, psicológico, jurídico ou financeiro.
