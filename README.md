# 🛡️ Bússola da Honra

**Coragem. Clareza. Honra.**

[Abrir o site público](https://aldenirfilho.github.io/bussola-da-honra-site/) · [Mapa de escolhas](https://aldenirfilho.github.io/bussola-da-honra-site/mapa.html) · [Agentes e habilidades](https://aldenirfilho.github.io/bussola-da-honra-site/agentes.html)

Edição espartana 1.5 · 31/10/2026. Proposta de Aldenir Rocha de Oliveira Filho, desenvolvida com assistência de IA.

Um espaço educativo de reflexão sobre fé, liberdade, dignidade, justiça e responsabilidade. HONRA significa **Honestidade, Olhar para todos, Não negociáveis, Rotas possíveis, Agir e aprender**.

- Roteiro de decisão em cinco etapas.
- Mapa para comparar duas alternativas, sem ranking moral.
- Seis assistentes guiados com instruções e habilidades para copiar ou baixar.
- Sete materiais de leitura editáveis.

As respostas ficam na memória da página. Baixe seu registro antes de fechar ou recarregar. O site não executa análise por IA nem transmite automaticamente suas respostas. Não usa API paga, rastreadores ou banco de dados. O provedor de hospedagem pode registrar acessos conforme suas regras.

## Distribuição

Este repositório contém a distribuição pública revisada, sem histórico privado, credenciais ou respostas de usuários. `PUBLICATION.json` registra a versão de origem e as somas de verificação. O GitHub Actions valida a distribuição antes de publicar somente os arquivos do site.

Para validar: `node .github/scripts/check-site.mjs` com Node.js 20 ou posterior. O site usa caminhos relativos e não requer instalação de dependências.

Para usar os agentes em outra ferramenta, baixe `assistentes/biblioteca-honra.zip` e leia o arquivo de instruções. Baixar não instala ou ativa agentes. O uso em ferramentas de IA depende do cliente e da conta de cada pessoa.

HONRA é uma proposta educativa, não uma escala clínica, psicológica, financeira ou jurídica validada. A decisão continua sendo sua. Autoria conceitual atribuída a Aldenir Rocha de Oliveira Filho; nenhuma licença aberta foi concedida. Fontes externas mantêm seus direitos.
